# Registre de capitalisation des constats de revue — Reco V1

Ce registre range les constats de revue du code et des outils de la V1 par familles (même défaut, sous des formes ou à des endroits différents) et nomme le contrôle automatique qui garde chaque famille, ou la consigne à défaut. Créé le 2026-11-14 à partir des constats déjà écrits ; règle C-1 du 2026-11-14 : une famille vue pour la deuxième fois devient un contrôle (test vu rouge sur le défaut réintroduit, règle du linter, vérification de type) ou, à défaut, une ligne de consigne dans le `CLAUDE.md` du projet.
À chaque PR, avant la fusion : relire les constats de la PR contre ce tableau. Si une famille y figure, ajouter l'occurrence (source, PR, tour) et, quand le statut est `à faire`, créer le contrôle dans la PR s'il est court (moins d'une heure), sinon dans la PR de ménage, noté au suivi ; il se vérifie par son propre test rouge puis vert, sans nouveau tour de revue.
Une famille vue une seule fois va dans « Constats isolés » en bas ; à la deuxième occurrence elle devient une ligne du tableau. Statuts : `gardé` (un contrôle automatique existe), `à faire` (contrôle proposé, pas encore écrit), `consigne` (pas de contrôle simple : une ligne à porter dans le `CLAUDE.md`).

## Sources et abréviations

- « PR #N r.K » : tour K de la revue de code de la PR N ; le commit de correction est cité par son numéro court (`4d894c60`). « I#N » : issue N. Les messages de commit décrivent le problème réel : ils sont la source des constats de #202 à #206, dont les relecteurs n'ont laissé aucun commentaire en ligne sur GitHub.
- EPIC-UI, EPIC-REV, EPIC-STAB, EPIC-LIENS, INTERFACE : rapports de `docs/` (`epic-ui-review-report-2026-07-06.md`, `epic-review-fixall-report-2026-07-19.md`, `epic-stabilite-rapport-2026-07-29.md`, `epic-liens-rapport-2026-08-18.md`, `interface-rapport-2026-10-07.md`). PIEGES : `docs/pieges-et-echecs.md`. SUIVI : le suivi privé du projet, rubrique « Pour plus tard » (hors dépôt).
- Fait vérifié = relu dans le code, la configuration ou l'historique le 2026-11-14 ; hypothèse = dit comme tel. Les chemins sont ceux de ce dépôt.
- Limite de ce relevé : seuls les résumés des constats sont conservés (messages de commit, rapports, suivi), pas les rapports bruts des relecteurs. Le code de la V2 a son propre registre et n'est pas repris ici.
