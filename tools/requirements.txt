# Pipeline de collecte « Reco » — dépendances Python (3.12)
# Installer dans un venv : voir tools/README.md
#
# Stratégie de versioning :
#  - On épingle un INTERVALLE (>=min, <maj-suivant) plutôt qu'une version
#    exacte. Avantages : on profite des correctifs (patch + mineur) sans se
#    prendre une rupture API d'une version majeure.
#  - Le bas de la fourchette est la version minimale réellement testée
#    localement ; le haut exclut la prochaine majeure (semver).
#  - Pour les libs sans versioning semver propre (yt-dlp, anthropic) on
#    laisse une borne basse seulement — leurs maj contiennent souvent des
#    fixes critiques (anti-blocage YouTube, nouveaux modèles).
#  - En cas de bug de reproductibilité, geler les versions exactes dans
#    un `requirements.lock` séparé (pip freeze) — laisser ce fichier
#    permissif pour le développement.

# Étape 1 — lecture du flux RSS Acast
feedparser>=6.0.14,<7

# Étape 2 — téléchargement + transcription locale
faster-whisper>=1.2.1,<2     # transcription Whisper en local (CTranslate2, CPU/GPU)
# PyAV est tiré par faster-whisper, qui le déclare `av>=11` sans borne haute. PyAV 19
# a retiré `metadata_errors` de `av.open()`, que faster-whisper 1.2.1 passe encore :
# toute transcription meurt sur `TypeError: open() got an unexpected keyword argument`.
# Mesuré le 2026-10-02 — l'image reconstruite ce jour-là a installé av 19.0.0 et ne
# transcrivait plus rien, là où celle du 2026-09-28 (av 18.1.0) marchait. À relever
# quand faster-whisper publiera une version qui n'utilise plus cet argument.
av>=11,<19
yt-dlp>=2026.8.19             # téléchargement audio YouTube (si pas d'audioUrl)
requests>=2.34.2,<3          # téléchargement des enclosures audio HTTP

# Étape 3 — extraction des recos via LLM
anthropic>=1.8.0            # SDK API Anthropic (modèle claude-opus-5)
openai>=3.19.2                # SDK OpenAI (provider LLM alternatif — testé dans test_extract_recos)
python-dotenv>=1.2.4,<2    # chargement de tools/.env (ANTHROPIC_API_KEY)

# Coordination cross-process (review_server ↔ scripts pipeline)
filelock>=4.0.3,<5          # verrou inter-processus (cf. tools/review_lock.py)

# Tests — parsing HTML structurel (review_server)
beautifulsoup4>=4.15.0,<5  # assertions DOM robustes aux changements de markup
responses>=0.26.3,<1         # mock des appels HTTP `requests` (enrich, fetch, ocr, transcribe)

# Cache HTTP SQLite pour `refresh_enrichment.py` (ADR 0023).
